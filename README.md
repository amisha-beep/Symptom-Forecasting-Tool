# Symptom Forecasting Tool

## Project Overview
This is an AI-inspired Symptom Forecasting Tool built using HTML, CSS, and JavaScript.

## Features
- User Sign Up and Sign In
- Dark Mode
- Symptom Selection
- Health Risk Assessment
- 7-Day Symptom Forecast
- Nearby Hospital/Clinic Finder using Location

## Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage
- Geolocation API
- Overpass API (OpenStreetMap)
